# 🤖 Telegram-бот: погода, мотивация, идеи для видео и дневник пробежек

## Что умеет
- Постоянные кнопки у клавиатуры: 🌤 Погода · 🏃 Записать пробежку · 🔗 Полезные ссылки (Strava, YouTube, Gemini) · ℹ️ О сервисе
- 05:00 — погода в Бишкеке + одна мотивация (81 вариант, без повторов подряд)
- 13:00 — одна идея для видео (60 вариантов)
- Запись пробежки: километры → минуты → самочувствие → итоги недели
- Без ИИ, ключ Gemini не нужен

Тестовые команды (сразу показывают сегодняшнее сообщение): /morning, /lunch. Узнать свой ID: /id.

## Render (Environment)
| Ключ | Значение |
|---|---|
| `BOT_TOKEN` | токен от BotFather |
| `OWNER_CHAT_ID` | ID из /id; несколько — через запятую |
| `DATABASE_URL` | строка подключения из Neon (см. ниже) |
| `PYTHON_VERSION` | 3.12.3 |

Build: `pip install -r requirements.txt` · Start: `python main.py`

## База Neon (нужна для записей пробежек)
1. https://neon.tech → Create project.
2. Connect → скопируй Connection string (`postgresql://...`).
3. Вставь в `DATABASE_URL` на Render и сохрани. Таблицы бот создаст сам.

Без `DATABASE_URL` бот работает, но записи пробежек и подписки стираются при перезапуске Render.

## Мониторинг 24/7
UptimeRobot → Add New Monitor → HTTP(s) → `https://ТВОЙ-СЕРВИС.onrender.com/health` → интервал 5 минут.

## Важно
- Один экземпляр бота на один токен (не запускай одновременно на компьютере и на Render).
- Рассылка отправляется строго один раз в день, даже если Render перезапустится (нужен `DATABASE_URL`).
- Время меняется переменными `MORNING_TIME`, `LUNCH_TIME`; часовой пояс — `TIMEZONE`.
- Токены никому не показывай. Если токен утёк — BotFather → `/revoke`.
